Two commands.
A window into your work.

Start with the sessions already on your machine.

  1. Install with Homebrew

    brew install mahata/tap/copilotview

    Requires Homebrew and a session history from the GitHub Copilot CLI or app. Homebrew installs Node.js for you.

  2. Start the local viewer

    copilotview serve

    This builds the search index and starts the web UI. Open http://127.0.0.1:4178 in your browser. The shorter cv serve works too.

Prefer to build from source or use a different session directory? See the README for setup and options.

Your history stays yours.

copilotview reads ~/.copilot/session-state/ without changing the source files and builds a separate search index at ~/.copilotview/index.db. Session content is not sent to external services.

It does not call an LLM to generate summaries. It brings together the messages, plans, summaries, and usage that your sessions already recorded.

This introduction is hosted on GitHub Pages. The viewer itself runs locally; there is no account to create or conversation history to upload.
